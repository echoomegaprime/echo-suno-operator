# Contributing

Enter through `AGENTS.md`. Use one isolated worktree and an `agent/*` branch per objective. Keep changes narrow, add regression coverage for every repaired failure, run the full Node test suite and a staged secret scan, and open a draft PR using the repository validation/security evidence format.

Do not commit production session material, alter public routing from a development test, automate CAPTCHA, auto-merge, force-push, or claim hosted/certification gates that were not read back for the exact SHA.
